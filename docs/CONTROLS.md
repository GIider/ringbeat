# Controls

## Keyboard
| Action | Keys |
|---|---|
| Lanes (4) | `D` `F` `J` `K` |
| Lanes (Easy, 3) | `F` `J` `K` |
| Menu navigation | Arrow keys (spatial focus), `Enter`/`Space` activate, `Tab` also works |
| Back / pause / resume | `Esc` |
| Restart (play, pause, results) | `R` |
| Sliders | `←` `→` |

## Touch
Tap and hold the lane columns (multi-touch). On-screen ❚❚ pauses. Menus are plain buttons.

## Gamepad (Standard Gamepad API)
Gameplay — defaults, each lane has several buttons:

| Lane | Buttons |
|---|---|
| 1 (left) | D-pad ←, X, LB, LT |
| 2 | D-pad ↓, A |
| 3 | D-pad ↑, Y |
| 4 (right) | D-pad →, B, RB, RT |

Easy (3 lanes) folds lane 1 and 2 onto the left lane, so every button stays live.
`Start` pauses, `Back/Select` restarts. Buttons are rebindable in Settings → Controller
(press the lane, then the button; a button belongs to at most one lane). Bindings are saved.

Menus:

| Action | Input |
|---|---|
| Move | D-pad or left stick |
| Adjust slider | ← → |
| Confirm | A (or Start) |
| Back | B |
| Difficulty − / + (song select) | LB / RB |
| Training options (song select) | Y |

A disconnect during play pauses the game. Notes: controllers appear to the browser only after the first button press.

## Tutorial
Shown automatically the first time you start the game (skipped for players who already picked a song). Four short stages teach taps, timing, holds and combo. Replay it from Settings → Replay tutorial.
