# Ringbeat

**Play now:** <https://giider.github.io/ringbeat/>

A browser rhythm game whose charts are generated automatically from RTTTL (Nokia ringtone) text, dressed up as a
late-90s candybar phone: every menu lives on the phone's green LCD, and during a song the note highway runs
right inside that LCD.
All sound is synthesized with the Web Audio API (default voice: a phone piezo buzzer). No dependencies, no build step;
the few assets (pixel font, phone artwork) are made in-repo — see below.

## Run

ES modules need an HTTP server (opening `index.html` via `file://` won't work). No dependencies; npm only runs the script:

```
npm start            # http://localhost:8000 (also prints LAN URLs)
npm start -- 9000    # custom port (or PORT=9000 npm start)
npm run dev          # same server, the page reloads whenever a file changes
npm run build        # stage runtime files into dist/ (what CI deploys to GitHub Pages)
npm run bench        # re-measure song difficulty with bots -> src/difficulty.json
npm run screenshots  # preview the README screenshots in docs/screenshots/ (git-ignored) from the ?demo= states (Playwright; palette-optimised if ImageMagick is installed)
npm run font         # rebuild assets/fonts/*.ttf after editing the glyphs in src/pixelfont.js
```

Screenshot states for development: `index.html?demo=play` (also `pause`, `menu`, `select`, `info`, `results`, `fc`,
`settings`, `stats`, `message`) loads the Nokia Tune and freezes a frame at ~10 %.

Versioning: `<major>.<minor>.<patch>` is derived, never edited by hand — major.minor = the newest entry in `src/changelog.js`, patch = commits since that entry was added (`scripts/version-lib.mjs`). To release a minor, add its changelog message. The GitHub Actions run number is shown separately as the build number.
Coverage: `node --test --experimental-test-coverage tests/*.test.mjs`.

Tests: `npm test` (node: core logic, font builder, sprites); `npm run smoke` drives the UI (`tests/smoke.html`) in headless
Chromium via Playwright (`npm install`, then once `npx playwright install chromium firefox webkit`; run other engines with `SMOKE_BROWSERS=firefox,webkit` and touch emulation with `SMOKE_DEVICE='iPhone 13'`). `tests/rtttl.test.html` and
`tests/smoke.html` also run by hand in a browser (title shows PASS/FAIL).
Git hooks (`.githooks/`, enabled by `npm install`): `pre-commit` runs the unit tests and checks `assets/fonts` matches `src/pixelfont.js`; `pre-push` runs `npm test`; `post-merge`/`post-checkout` re-run `npm install` when `package-lock.json` changes. Skip with `--no-verify`.

## Deployment

Every push to `main` runs the tests, builds `dist/` (version from the changelog, see Versioning), publishes it as the `latest`
pre-release and deploys it to GitHub Pages ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)).

## Features

3310-style main menu (Tones, My songs, Stats, Messages, Profile, Settings) with animated icons · lifetime stats (playtime,
score, grades, streaks) · changelog delivered as SMS · English and German (follows the browser language, switchable in Settings) ·
song select with 153 built-in songs (11 full-length) + custom/share links · 3 difficulties · local highscores (top 5 per song/difficulty) ·
full combo / all perfect indicators · timing display · modifiers (speed, mirror, hidden, sudden death, judging; score multiplier; demo autoplay, x0 and never saved) ·
keyboard, touch and gamepad (rebindable) · latency calibration · Nokia-style phone UI with clickable phone keys ·
buzzer or smooth instrument voice.

## Assets

Everything visual is made here, no external fonts or images:

- `src/pixelfont.js` — hand-drawn 5×7 LCD font (ASCII + UI symbols). `scripts/build-font.mjs` compiles it to
  TrueType (`assets/fonts/rb-pixel.ttf` + a bold cut); text is crisp at multiples of 10 px.
- `assets/phone.svg` — the phone shells; the LCD and key hit areas are DOM laid over them.
- `src/pixelart.js` — 1-bit sprites (signal bars, battery, ringing phone, category icons) used as CSS masks.
- `src/menuicons.js` — the animated main-menu icons (folder card + symbol + pressing hand), drawn in code.
- `src/cover.js` — per-song 72×28 "picture message" art, generated from the song id.

## Controls

`D F J K` (4 lanes) · tap lanes on touch · gamepad d-pad/face buttons/shoulders · `Esc` pause · `R` restart.
Menus: arrows, `Enter`, `Esc`/`Backspace`, `1`–`6` main-menu items, `O` song-list options — or click the phone's Menu, C and ▲▼ keys and keypad.

## RTTTL format notes

`name:d=4,o=5,b=125:8e6,8d6,p,4c#.,...`

- Defaults `d` (duration), `o` (octave 4–7), `b` (BPM); any may be missing (fallback d=4, o=6, b=63).
- Note: `[duration][note][#][.][octave][.]` — a dot is accepted after the note letter or after the octave.
  The dot always follows the note: dotted quarter C is `4c.` (or `4c5.`), never `4.c` — a dot in front of the note is
  an unknown token and the note is skipped (listed as a warning).
- `p` is a pause. Octave 4 means C4 = MIDI 60 (middle C); A4 = 440 Hz.
- Whitespace and case are ignored; unknown tokens are skipped and listed as warnings.

## Sharing

"My songs → (song) → Copy share link" puts the song in the URL hash (`#s=<base64url>`). Opening it selects the custom song (no autoplay).

## Song sources & credits

The built-in songs are short RTTTL transcriptions of existing melodies; the tunes belong to their composers and rights
holders. The RTTTL strings come from:

- **PICAXE RTTTL archive** — <https://picaxe.com/rtttl-ringtones-for-tune-command/>
  (zips: [rtttl](http://picaxe.com/downloads/rtttl.zip), [rtttl2](http://picaxe.com/downloads/rtttl2.zip),
  [rtttl3](http://picaxe.com/downloads/rtttl3.zip), [rtttl_tv](http://picaxe.com/downloads/rtttl_tv.zip),
  [rtttl_xmas](http://picaxe.com/downloads/rtttl_xmas.zip)) — German/European songs, pop, Eurodance, TV & Film.
- **FlipperMusicRTTTL** — <https://github.com/neverfa11ing/FlipperMusicRTTTL> (incl. ArcadeTones and the 10k song
  archive) — NDW & Synth and Video Games additions.
- **Traditional / public-domain tunes** (classical, folk, nursery, and the "Full" arrangements) were written by hand.

Credit is per collection, not per song. RTTTL format reference:
[Wikipedia](https://en.wikipedia.org/wiki/Ring_Tone_Text_Transfer_Language).
